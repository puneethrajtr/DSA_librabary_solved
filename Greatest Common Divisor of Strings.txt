# 1071. Greatest Common Divisor of Strings

## Problem Statement

For two strings `s` and `t`, we say **"t divides s"** if and only if `s` can be formed by concatenating `t` one or more times.

Given two strings `str1` and `str2`, return the **largest string** `x` such that `x` divides both strings.

---

## Pattern

- Mathematics (Greatest Common Divisor)
- String Pattern Matching

---

## Data Structures Used

- String

---

## Intuition

The common divisor string must be able to generate both strings by repeating itself multiple times.

Instead of checking every possible substring, we make two important observations:

1. If `str1 + str2` is **not equal** to `str2 + str1`, then both strings are not formed from the same repeating pattern. In this case, no common divisor string exists.

2. If they are equal, then the length of the largest possible divisor string is the **Greatest Common Divisor (GCD)** of the lengths of both strings.

Finally, return the first `gcd(len(str1), len(str2))` characters of `str1`.

---

## Why This Approach Works

Suppose,

```text
str1 = "ABCABC"
str2 = "ABC"
```

Both strings are formed by repeating `"ABC"`.

```
ABCABC + ABC = ABCABCABC
ABC + ABCABC = ABCABCABC
```

Since both concatenations are equal, both strings share the same repeating pattern.

Now,

```
len(str1) = 6
len(str2) = 3

gcd(6,3) = 3
```

The first 3 characters of `str1` are `"ABC"`, which is the largest string that divides both strings.

If the concatenations are different, such as:

```
str1 = "LEET"
str2 = "CODE"

LEETCODE ≠ CODELEET
```

then no common divisor string exists, so return an empty string.

---

## Algorithm

1. Check whether `str1 + str2` is equal to `str2 + str1`.
2. If they are not equal, return an empty string.
3. Compute the GCD of the lengths of both strings.
4. Extract the first `gcd(len(str1), len(str2))` characters from `str1`.
5. Return the extracted substring.

---

## Python Solution

```python
class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:

        def gcd(n, m):
            greatest_divisor = 0
            for i in range(1, max(n, m) + 1):
                if n % i == 0 and m % i == 0:
                    greatest_divisor = max(greatest_divisor, i)
            return greatest_divisor

        if str1 + str2 == str2 + str1:
            g = gcd(len(str1), len(str2))
            return str1[:g]

        return ""
```

---

## Complexity Analysis

### Time Complexity

- Concatenation comparison: **O(n + m)**
- GCD calculation (current implementation): **O(max(n, m))**
- Extracting substring: **O(g)**

Overall:

```
O(n + m + max(n, m))
```

---

### Space Complexity

```
O(1)
```

(ignoring the returned string)

---

## Optimization

Instead of finding the GCD using a loop, we can use the Euclidean Algorithm.

```python
from math import gcd

g = gcd(len(str1), len(str2))
return str1[:g] if str1 + str2 == str2 + str1 else ""
```

The Euclidean Algorithm computes the GCD in:

```
O(log(min(n, m)))
```

which is much faster for larger inputs.

---

## Key Takeaways

- Always look for mathematical properties before brute-forcing string problems.
- The equality `str1 + str2 == str2 + str1` is a powerful way to verify that two strings share the same repeating pattern.
- The length of the answer is determined by the **Greatest Common Divisor (GCD)** of the string lengths.
- Using the Euclidean Algorithm further optimizes the solution.
