LeetCode 3870 – Count Commas in Range

Problem Statement

Given an integer n, return the total number of commas used when writing all integers from 1 to n inclusive in standard number formatting.

A comma is inserted after every three digits from the right.

Numbers containing fewer than four digits do not contain commas.

Example 1

Input:
n = 1002

Output:
3

Explanation:

The numbers:

1,000
1,001
1,002

each contain exactly one comma.

Therefore:

3 numbers × 1 comma = 3

Example 2

Input:
n = 998

Output:
0

Explanation:

Every number from 1 through 998 contains fewer than four digits.

Therefore, no commas are used.

Mathematical Observation

The important point is that a number receives its first comma when it reaches 1000.

All numbers from:

1000 to n

contain exactly one comma, provided n <= 100000.

Because the constraint is:

1 <= n <= 10^5

no number in the range can contain more than one comma.

Therefore, the problem becomes:

How many integers are present in the range [1000, n]?

Counting the Numbers

If n < 1000:

There are no numbers containing commas.

Answer:

0

If n >= 1000:

The number of integers from 1000 through n is:

n - 1000 + 1

The +1 is necessary because both endpoints are included.

For example:

n = 1000

Number of integers in [1000, 1000]:

1000 - 1000 + 1 = 1

Therefore, the answer is 1.

Algorithm

1. Check whether n is less than 1000.

2. If n < 1000, return 0.

3. Otherwise, calculate:

   n - 1000 + 1

4. Return the result.

Python Implementation

class Solution:

```
def countCommas(self, n: int) -> int:

    if n < 1000:
        return 0
    else:
        return (n - 1000) + 1
```

Why Does This Work?

Numbers below 1000 have fewer than four digits, so they do not contain commas.

Starting from 1000, every number contains exactly one comma.

Because n is at most 100000, no number can contain two or more commas.

Therefore, the total number of commas is exactly equal to the number of integers from 1000 through n.

The number of integers in an inclusive range [1000, n] is:

n - 1000 + 1

Therefore, the formula gives the exact answer.

Correctness

Case 1: n < 1000

Every number from 1 to n has at most three digits.

Therefore, no commas are used.

The algorithm returns 0, which is correct.

Case 2: n >= 1000

Every integer from 1000 through n contains exactly one comma.

Every integer below 1000 contains zero commas.

Therefore, the total number of commas equals the number of integers in the range [1000, n].

That count is:

n - 1000 + 1

Therefore, the algorithm returns the correct answer.

Time Complexity

O(1)

The algorithm performs only a comparison and a constant amount of arithmetic.

It does not iterate through the numbers from 1 to n.

Therefore, the running time is constant regardless of the value of n.

Time Complexity:

O(1)

Auxiliary Space Complexity

O(1)

Only a constant amount of additional memory is used.

No arrays, lists, strings, loops, or other data structures are required.

Auxiliary Space Complexity:

O(1)

Is This Optimal?

Yes.

O(1) is asymptotically optimal time complexity.

There is no meaningful Big-O time complexity better than O(1), because an algorithm must perform at least some constant amount of work to produce an answer.

Therefore:

Time = O(1)
Auxiliary Space = O(1)

is the optimal complexity for this problem.

Important Learning

This problem does not require a complicated algorithm or data structure.

The key skill is recognizing the mathematical pattern.

Instead of doing:

for every number from 1 to n:
count its commas

which would require O(n) time, we observe that:

• 1 to 999 → 0 commas
• 1000 to n → 1 comma per number

Therefore, we can directly calculate the answer using arithmetic.

Final Takeaway

The key observation is:

"Every number from 1000 through n contributes exactly one comma."

Therefore:

If n < 1000:

answer = 0

Otherwise:

answer = n - 1000 + 1
